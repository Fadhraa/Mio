# Mio Windows Notch (Native Rust)

Ambient Dynamic Notch untuk Windows 10/11 yang terhubung langsung ke ekosistem Mio ([apps/tracking](file:///d:/coding/Mio/apps/tracking) dan [apps/assistant](file:///d:/coding/Mio/apps/assistant)).

## Spesifikasi & Filosofi Desain
- **Ultra-Ringan:** Target RAM < 20 MB dan CPU 0.0% saat idle (event-driven rendering).
- **Zero Browser Engine:** Murni native executable tanpa Electron atau WebView.
- **Dynamic State:** Mode *Collapsed* (indikator pil kecil), *Hovered* (preview aktivitas fokus), dan *Expanded* (ringkasan briefing & quick chat Mio).
